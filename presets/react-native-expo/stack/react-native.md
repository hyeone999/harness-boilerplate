# React Native 체크 항목

## setState 업데이터는 순수해야 한다

업데이터 함수는 렌더 단계에서 호출되며 호출 시점이 보장되지 않는다. 부수효과를 넣거나 외부 변수에 대입하고 그 값을 동기적으로 읽으면 안 된다.

❌

```ts
let next = false;
setStatus((prev) => {
  next = !prev[key]; // 외부 변수 대입
  AsyncStorage.setItem(...); // 부수효과
  return { ...prev, [key]: next };
});
return next; // 업데이터 실행 보장 없음
```

평소엔 동작하지만 이전 업데이트가 처리 중이면 지연된다. 빠르게 두 번 탭하면 반환값이 초기값으로 나온다.

✅ ref로 최신값을 들고 있거나, 다음 값을 먼저 계산한 뒤 setState를 호출한다.

## Linking.openURL은 실패한다

앱 미설치·잘못된 스킴이면 reject된다. try/catch로 잡고 사용자에게 알린다.

## 원격 이미지는 실패·누락을 함께 처리한다

`onError`와 URL 누락을 모두 다룬다. 공용 폴백 이미지 컴포넌트를 쓴다.

`uri`가 바뀔 때 에러 상태를 리셋하지 않으면 리스트 재사용 시 이전 실패가 남는다.

## 원격 SVG는 빈 응답에 대비한다

`SvgUri`는 빈 응답이나 잘못된 SVG에서 크래시할 수 있다. 실패 시 폴백을 둔다. 래스터 이미지를 감싼 SVG는 `color`로 색을 바꿀 수 없다.

## 애니메이션 useEffect 의존성

`useEffect(..., [])`로 마운트 1회만 실행할 때, 참조하는 값이 바뀌어도 재실행되지 않는다는 점을 주석으로 남긴다.

## 아이콘·이미지 에셋

- 색만 다른 SVG를 여러 개 만들지 않는다. `fill="currentColor"` 하나로 두고 `color` prop으로 바꾼다
- 배경 원·박스·dim은 SVG에 넣지 않고 스타일로 처리한다
- 같은 용도의 에셋은 크기를 맞춘다. 한 파일만 470px·178KB이고 나머지가 150px·10KB 안팎이면 최적화 누락이다

## 네이티브 의존성 변경

`package.json`에 네이티브 모듈이 추가·변경되면 JS 리로드로는 반영되지 않는다. 네이티브 재빌드(`expo run:ios` / `prebuild`)가 필요하다고 PR에 적는다.
